## Overview

[Oruk](https://oruk.ai) serves the Fourier 2B English speech-to-text model (`oruk-fourier-2b`) through an OpenAI-compatible `/v1/audio/transcriptions` endpoint. Key characteristics:

- **Batch Speech-to-Text** - Multipart audio transcription up to 30 MiB / 60 minutes per file
- **English-focused ASR** - Accepts optional English language hints (`en`, `en-US`, `en-GB`); non-English codes fail fast with HTTP 400
- **Strict request sanitization** - Oruk enforces strict field validation (`additionalProperties: false`), so Bifrost forwards only `file`, `model`, `response_format` (`json`, `verbose_json`, or `text`), and `language`
- **Hosted pricing** - `$0.0080/minute` (`$0.0001333333/second`) via the commercial Speech API; open weights (`oruk/oruk-fourier-2b`, 2.04B parameters, `CC BY-NC 4.0`) can also be self-hosted by setting `network_config.base_url`
- **Authentication** - `Authorization: Bearer <key>` on every call

### Supported Operations

| Operation | Non-Streaming | Streaming | Endpoint |
|-----------|---------------|-----------|----------|
| Transcription (STT) | ✅ | ❌ | `/v1/audio/transcriptions` |
| List Models | ✅ | - | Static catalog (`oruk-fourier-2b`) |
| Speech (TTS) | ❌ | ❌ | - |
| Chat Completions | ❌ | ❌ | - |
| Responses API | ❌ | ❌ | - |
| Text Completions | ❌ | ❌ | - |
| Embeddings | ❌ | ❌ | - |

<Note>
**Unsupported Operations** (❌): Chat, Responses, Text Completions, Embeddings, Speech (TTS), Images, Video, Files, Batch, and streaming transcription return `UnsupportedOperationError`.
</Note>

## Setup & Configuration

Bifrost calls `https://speech-api.oruk.ai` by default and appends `/v1/audio/transcriptions`. Set `network_config.base_url` to point at a self-hosted OpenAI-compatible Fourier 2B server.

<Tabs>
<Tab title="Web UI">

1. Navigate to **Models** > **Model Providers**. Look for **Oruk** under **Configured Providers**. If it is missing, click **Add New Provider** and select **Oruk**.
2. Click **Add Key** or edit an existing key.
3. Set a name for your key.
4. Paste your API key directly or use an environment variable (for example, `env.ORUK_API_KEY`).
5. Set **Allowed Models** to **All Models** (default) or `oruk-fourier-2b`.
6. Save the provider configuration.

</Tab>
<Tab title="config.json">

```json
{
  "providers": {
    "oruk": {
      "keys": [
        {
          "name": "oruk-key-1",
          "value": "env.ORUK_API_KEY",
          "models": [
            "*"
          ],
          "weight": 1.0
        }
      ]
    }
  }
}
```

</Tab>

</Tab>

## Transcription Example

```bash
curl -X POST http://localhost:8080/v1/audio/transcriptions \
  -F "file=@sample.wav" \
  -F "model=oruk/oruk-fourier-2b" \
  -F "language=en" \
  -F "response_format=json"
```

## Pricing Configuration

For local pricing files or custom datasheet overrides, configure `oruk-fourier-2b` at `$0.0080/minute` (`0.00013333333333333334` USD per audio second):

```json
{
  "oruk/oruk-fourier-2b": {
    "mode": "audio_transcription",
    "provider": "oruk",
    "base_model": "oruk-fourier-2b",
    "input_cost_per_audio_per_second": 0.00013333333333333334
  }
}
```
