<Update label="Bifrost(HTTP)" description="1.5.1">
## ✨ Features

- **Azure Entra Auth** - Added `client_id`, `client_secret`, `tenant_id`, `scopes` fields to the Azure transport schema and made `api_version` optional
- **UBI9 Docker Builds** - Added UBI9 amd64/arm64 Docker build and multi-arch manifest jobs to the release pipeline
- **Configurable Matview Refresh** - Added `matviewRefreshInterval` config option and bumped the bifrost chart to 2.1.15
- **Per-dimension Matviews** - Split `mv_logs_filterdata` into per-dimension matviews and added filterdata response caching with single-flight
- **Dimension-scoped Filters** - Added `?dimensions=` parameter for filter data endpoints with a time-window hybrid matview gate and scoped dimension fetching for log and MCP filter sidebars
- **x-bifrost-* Response Headers** - Surface routed identity (provider, model, key alias, etc.) as `x-bifrost-*` response headers (thanks [@Edward-Upton](https://github.com/Edward-Upton)!)
- **Normalized Model Names** - `ListModels` response now includes a `normalized_name` parameter
- **Azure Blob Batch Storage** - Added Azure blob storage fields for the batch API
- **WS Tickets Without Storage** - WebSocket tickets are now issued without backing storage
- **MCP Log Detail & Object Storage** - Added MCP log detail endpoint with object-storage payload offload, batch logging for MCP, and detail view in the UI
- **Retry Count Metric** - Added a number-of-retries metric to OTEL and telemetry plugins
- **Cached Token Details in OTEL** - Added cached token details for the Responses API in OTEL exports
- **Bedrock Region from Model Name** - Region is now extracted from the model name when passing through Bedrock models
- **ListModels Removed From Rate Limit/Quota** - Governance no longer invokes ListModels for rate limit and quota checks
- **JSON Log Detail Rendering** - JSON text content is now rendered as formatted code in the log detail view
- **x-operation-id Approval** - Added approval flow for operation IDs
- **Prometheus Plugin Cleanup** - Removed system metrics from the prometheus plugin and added additional types

## 🐞 Fixed

- **PostgreSQL `\u0000` Sanitization** - Sanitize `\u0000` from JSON before PostgreSQL jsonb storage and list queries
- **Lock-safe Matview Maintenance** - Use batched updates, `CONCURRENTLY` indexes, and advisory locks for matview and migration maintenance
- **pg_advisory_lock Retry+Timeout** - Replaced blocking `pg_advisory_lock` with retry+timeout to prevent indefinite startup hangs
- **Empty MCP Config** - Return an empty MCP config instead of `nil` when no clients are found
- **Gemini Image Size Casing** - Removed lowercase normalization on image size in Gemini image requests
- **Bedrock Reasoning Display** - Reasoning display shorthand and set `display=summarized` for Responses on Bedrock
- **Gemini JSON Schema for Vertex** - Normalize JSON Schema union types for Vertex compatibility
- **RDB Deadlock Fixes** - Resolved deadlocks in the rate-limit DB path
- **xhigh Effort Mapping** - Added xhigh effort mapping for GPT 5.4+
- **Plugin Trace-Attribute Flow** - Updated `context.SetTraceAttribute` flow across all plugins
- **Opus 4.7 Reasoning Default** - Default `display=summarized` for Opus 4.7 reasoning
- **Gemini Video Download** - Fixed video download for the Gemini provider
- **Claude Code Native Converters Fallback** - Fallback to native converters for Claude Code when an output format is set on the Vertex messages API
- **Gemini `tokenCount` Always Included** - Always include `tokenCount` in Gemini modality usage details (thanks [@R-droid101](https://github.com/R-droid101)!)
- **Tool Choice Any in GenAI** - Handle `tool_choice=any` in the GenAI roundtrip
- **OTEL `anyOf` Schema** - OTEL plugin now uses `anyOf` instead of `oneOf` to correctly validate `host:port` format for the gRPC schema
- **scim_config Keycloak Alignment** - Aligned `scim_config` schema with the documented Keycloak provider (thanks [@lornest](https://github.com/lornest)!)
- **Docker Volume Path** - Aligned Docker volume with the configured app directory (thanks [@EzgiTastan](https://github.com/EzgiTastan)!)
- **OAuth Flow Preservation** - Don't clear `oauthFlow` on OAuth error
- **MCP OAuth Window Null** - Fixed MCP OAuth window null issue
- **Governance Video/Passthrough Types** - Updated video and passthrough request types in governance that do not require a model field
- **Custom Provider Sheet Layout** - Custom provider sheet header and footer are now sticky with proper padding and a scrollable content area
- **Empty Filter Section Visibility** - Prevent filter sections from hiding when opened with empty data
- **Config JSON Client Credentials** - Restored client id and secret in the config JSON output

</Update>
