<Update label="Bifrost(HTTP)" description="1.5.6">
## ✨ Features

- **Direct API Key Header** - Pass a provider API key directly via request header
- **MCP Per-User Authentication** - New per-user header auth type with credential storage and lazy-auth submission flow
- **MCP TLS Configuration** - Configurable TLS (insecureSkipVerify, caCertPem) for HTTP/SSE MCP client connections
- **MCP Sessions Management** - Filter, search, and pagination on the MCP sessions list API and table, plus a can_reauth identity gate
- **Tool Call Execution UI** - Inline tool-call execution, stop streaming, bulk execute/submit, and a redesigned tool-call UI
- **Dimension Rankings Dashboard** - New dashboard tabs for team, customer, BU, and user rankings, backed by a GetDimensionRankings API
- **Model Pricing Attributes** - additional_attributes on model pricing rows with management API and UI editor
- **Prompt Cache Retention** - Prompt cache retention parameter on responses requests
- **Opus 4.8 Support** - System message handling and compatibility for Opus 4.8
- **Key Rotation** - Rotate keys on 401/402/403 and return 502 upstream_credentials_exhausted when all keys are permanently dead
- **OTel Metrics** - OTel spec compatible metrics plus provider and semantic cache attributes in metrics export
- **Sheet Navigation** - Prev/next keyboard navigation and URL state across virtual key, MCP client, and routing rule sheets
- **Go 1.26.3** - Upgraded toolchain to Go 1.26.3

## 🐞 Fixed

- **Bedrock Tool Names** - Truncate Bedrock function/tool names to the provider length limit
- **Bedrock Guardrails** - Set guardrail config in Bedrock request built from responses
- **Anthropic Tool Use** - Default Anthropic tool_use input to {} when arguments are absent
- **Responses Streaming** - Fixed responses stream events
- **Compat Flow** - Fixed missing parameter parsing on the compat flow
- **Passthrough API Version** - Set a default API version in passthrough requests as a fallback
- **Virtual Key Updates** - Avoid overriding optional fields during virtual key update
- **User-Mode Flows** - Gate user-mode flows on caller user_id, skip temp token mint, and unify flow/credential kind filtering for pending flows
- **Partial Tool Calls** - Handle partial tool call execution failures and return successful results
- **URL Query Escaping** - Support escaped characters in URL query parameters
- **MCP Auth Errors** - Inline banner and retry support for MCP auth-required errors
- **JSON Editor Height** - Cap JSON editor max height at 400px in message views

</Update>
