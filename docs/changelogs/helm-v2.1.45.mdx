<Update label="Bifrost Helm" description="v2.1.45">

## Changelog

- Added `bifrost.client.a2aPrivateAllowlist`, rendered as `client.a2a_private_allowlist`, to permit private destinations for Agent Gateway card discovery, OAuth, and runtime connections. Link-local and cloud metadata destinations remain blocked.
- Added `bifrost.agents[].credential_origins`, rendered as `agents[].credential_origins`, to permit additional HTTP(S) origins for agent runtime requests. The agent card origin is permitted automatically.
- Added `bifrost.client.skillsExternalClientUrl` (`client.skills_external_client_url`) for the public skills marketplace URL, including environment and vault references. When unset, marketplace serving is disabled; skill management and downloads remain available.
- Updated `bifrost.client.a2aExternalClientUrl` (`client.a2a_external_client_url`) to accept secret-reference objects and document that an unset URL disables all Agent Gateway protocol endpoints while management remains available.

</Update>
