<Update label="Bifrost(HTTP)" description="1.5.3">
## ✨ Features

- **Temporary Access Tokens** - Short-lived access tokens for scoped, time-limited API access
- **MCP Per-User OAuth** - Refactored MCP OAuth into a per-user flow
- **Bedrock Mantle Engine** - Bedrock Mantle inference engine support for `gpt-oss` models via an OpenAI-compatible SSE endpoint
- **Azure Realtime Provider** - Azure realtime provider with nested model normalization, plus enriched realtime routing, logging, cost, and session tracking
- **Bedrock System Tools** - System tool support for Bedrock models
- **Service Tier Mappings** - Service tier mappings for Gemini and Anthropic
- **Team-Level Calendar Alignment** - Calendar-aligned budgets at the team level
- **Feature Flags** - Feature flag framework for gating functionality
- **Config Hash Override** - File values in `config.json` now override DB values when the file changes between restarts; `model_parameters_url` is configurable via config JSON and Helm chart
- **Direct Access Control** - `access_profile_id` on virtual keys for direct access profile assignment, plus DAC support
- **Virtual Key Rotation** - Rotate virtual keys from the UI and backend
- **Cluster-Aware Logging** - Cluster-aware log metadata and per-node usage aggregation
- **Dashboard RBAC** - Granular RBAC for API keys, inference, metrics, MCP logs, and dashboard access, with inaccessible sidebar items filtered
- **Onboarding Widget** - Onboarding setup checklist widget with backend support
- **Broker Mode** - Broker mode schema and configuration
- **Server-Side Filter Search** - Server-side search and pagination on filter sidebar checkbox lists via a debounced `q` query param
- **OTEL Plugin Selection** - Custom selection of plugins for OTEL trace-span exports
- **UI Action Menus** - Inline action buttons replaced with pinned dropdown menus across teams, virtual keys, MCP clients, pricing overrides, routing rules, model limits, and logs tables
- **Dashboard Chart Polish** - Animated totals/averages and full-precision tooltips on chart card headers

## 🐞 Fixed

- **fasthttp Panic** - Fixed a fasthttp panic on malformed requests
- **Streaming Stability** - Fixed a remote-stream-close race on context cancel, a nil pointer deref in stream cancellations, idle stream timeouts, and context-cancel ordering before read errors
- **Bedrock Fixes** - Bedrock Mantle fixes, chat tool arguments, stop reason, missing lifecycle events, and Responses prefill handling
- **OpenAI Responses** - Preserve OpenAI responses stream metadata and add usage to the completed event in the Responses-to-Chat-Completions fallback (thanks [@etnperlong](https://github.com/etnperlong)! and [@kevinpdev](https://github.com/kevinpdev)!)
- **Anthropic Fixes** - Set Anthropic beta headers on Vertex, emit role chunk from message start, trim trailing whitespace, fix reasoning-content forwarding on Responses->Chat conversion, and preserve output schema refs (thanks [@Javtor](https://github.com/Javtor)!)
- **Gemini Fixes** - Remove the non-native `fallbacks` key from Gemini requests
- **Pricing Overrides** - VK and provider-key level pricing overrides now apply to streaming requests
- **Secret Redaction** - `FullyRedacted()` for proxy passwords and `MarshalForStorage()` for `ProxyConfig` prevent partial value leakage in API responses
- **Calendar-Aligned Migrations** - Multiple migration fixes for calendar-aligned budget tables
- **Semantic Cache** - Dimension check on namespace creation, double-close panic guard, request-time plugin resolution, and telemetry decoupling
- **Filter Queries** - Removed the `defaultFilterDataLimit` cap and skip pagination clamp on VK export requests
- **MCP Logs** - Remove stale stats from the logs list response
- **configstore** - Improve error message when an API key name conflicts across providers
- **DB Safety** - Replace unsafe inline jsonb cast with a `bifrost_safe_jsonb` PL/pgSQL helper
- **Azure Batch** - Include Azure blob fields in batch responses
- **UI Fixes** - Validate OAuth popup messages, constrain table column widths, fix provider API structure form padding, and pass through extra image params (thanks [@binbandit](https://github.com/binbandit)! and [@d3lm](https://github.com/d3lm)!)
- **Security Dependencies** - AWS SDK and dependency updates for security patches

</Update>
