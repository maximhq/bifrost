[feat]: PostgreSQL LISTEN/NOTIFY config sync across pods. `RDBConfigStore` publishes a `pg_notify` on `bifrost_config_sync` after every config-mutating write (providers, keys, virtual keys, VK provider/MCP configs, client config, MCP clients, plugins, routing rules, teams, customers, budgets, model configs, pricing overrides, virtual MCPs, webhook endpoints), and exposes an optional `ConfigChangeListenable` interface backed by a dedicated `pgx` connection that `LISTEN`s for those events with exponential-backoff reconnect. SQLite stores are unaffected; usage counters (`UpdateBudgetUsage`, `UpdateRateLimitUsage`) and derived state (`UpdateMCPClientTools`, `UpdateStatus`) intentionally do not publish, since they are already synced by their own periodic dump/discovery cycles
