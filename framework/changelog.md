## ✨ Features

- **Virtual Key Rotation Grace Period** - Setting `vk_rotation_cooldown` to 0 now also revokes grace windows that are already open, via the new `ConfigStore.RevokeVirtualKeyRotationGrace`. The cooldown is stamped onto `previous_value_expires_at` at rotation time and never re-read, so clearing it previously changed only what future rotations stamped and retired values kept authenticating for the rest of their original window. Already-expired leftovers are swept in the same pass, so retired secret material no longer lingers on the row indefinitely. The governance store gained a matching in-memory `RevokeRotationGraceInMemory` sweep that touches no database.
- **Virtual Key Rotation Grace Period** - New rotation-state columns on `governance_virtual_keys` (`previous_value`, `previous_value_hash`, `previous_value_expires_at`, `rotated_at`) with encryption support, plus a `vk_rotation_cooldown` client config setting (duration string, default 0 = immediate flip) controlling how long a rotated-out key value keeps authenticating.
