- [fix]: the opencode `x-opencode-session` affinity header now reaches upstream on large-payload requests too. It is emitted through the provider's extra-header map rather than a `BodySigner`, because a signer only runs on the paths where the handler marshaled the body itself — the large-payload passthrough streams the transport's deferred reader straight to upstream and has no marshaled body to sign, which silently dropped the header on exactly the long conversations carrying documents or images. A static `network_config.extra_headers` entry for the same header is now overridden by the resolved per-request value instead of racing it (@midhunvnadh)
