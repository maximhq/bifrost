- feat: native `x-bf-request-timeout` total deadline for a request or stream, independent of `x-bf-stream-idle-timeout` (#4805). One budget covers every fallback attempt and MCP agent turn, and no fallback starts once it fires. A fired deadline ends a stream with a terminal `504 request_timed_out` chunk, fails a non-streaming request with 504 rather than 499, cancels only its own request, and sets `BifrostContextKeyRequestTimeoutFired` so plugins can tell it from a caller cancellation (thanks [@public-aanp-tanium](https://github.com/public-aanp-tanium)!)
